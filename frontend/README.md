# Frontend

Next.js (App Router, TypeScript, Tailwind) frontend for the Islamic
reflection assistant. Talks to the FastAPI backend in `../backend` over
HTTP -- see the repo root [README.md](../README.md) for the full
architecture, setup, and deployment instructions.

## Quick start

```bash
npm install
cp .env.example .env.local   # set NEXT_PUBLIC_API_BASE_URL to the backend's URL
npm run dev
```

Requires the backend (`../backend`) running separately -- see the root
README's "Setup" section for both at once.

## Structure

- `src/app/page.tsx` -- thin server component, renders `<ReflectionApp />`.
- `src/components/ReflectionApp.tsx` -- the only stateful client component:
  emotion buttons, free-text input, result display, "give me another
  reminder" flow.
- `src/components/SourceCard.tsx` -- renders one Qur'an/hadith/dua source
  (Arabic, transliteration, translation, citation).
- `src/components/VideoGrid.tsx` -- YouTube-style thumbnail grid for
  related videos.
- `src/lib/api.ts` + `types.ts` -- typed fetch wrapper around
  `POST /api/reflect`.

## Commands

```bash
npm run dev      # local dev server
npm run build    # production build + typecheck
npm run lint     # ESLint
npm start        # run a production build locally
```
